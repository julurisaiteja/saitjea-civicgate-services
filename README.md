# CivicGate

Citizen services that feel clear, calm, and accountable.

**Style:** Gov Swiss Clarity  
**Diamond batch:** 4 (#40)  
**Mode:** Citizen services portal (permits, fees, filings) — not a shop metaphor.

## Run locally

```bash
npm i
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
npm run build
npm start
```

## Features

- Homepage film (autoplay muted loop + poster fallback)
- AI assistant with niche Q&A
- Offers / coupon `EARLYBIRD`
- Reviews, deep catalog (search/filter/sort), PDP specs & FAQ
- Service basket → fee checkout → filing receipt
- Niche desk: `/filings` (Filings)
- Locations, journal, account/loyalty teaser, newsletter
- Soft motion + reduced-motion respect
